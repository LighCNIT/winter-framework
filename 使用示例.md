# Winter Framework 使用示例

## 一、快速开始

### 1.1 创建一个具体的 BeanFactory 实现

首先需要创建一个继承 `AbstractAutowireCapableBeanFactory` 的具体实现类，实现 `getBeanDefinition` 方法：

```java
package org.winterframework.beans.factory.support;

import org.winterframework.beans.BeanException;
import org.winterframework.beans.factory.config.BeanDefinition;

import java.util.HashMap;
import java.util.Map;

/**
 * 默认可列表的 Bean 工厂
 * 实现了 BeanDefinitionRegistry 接口，可以注册和管理 BeanDefinition
 */
public class DefaultListableBeanFactory extends AbstractAutowireCapableBeanFactory 
        implements BeanDefinitionRegistry {

    // 存储 BeanDefinition 的 Map
    private Map<String, BeanDefinition> beanDefinitionMap = new HashMap<>();

    @Override
    public void registerBeanDefinition(String beanName, BeanDefinition beanDefinition) {
        beanDefinitionMap.put(beanName, beanDefinition);
    }

    @Override
    protected BeanDefinition getBeanDefinition(String beanName) throws BeanException {
        BeanDefinition beanDefinition = beanDefinitionMap.get(beanName);
        if (beanDefinition == null) {
            throw new BeanException("No bean named '" + beanName + "' is defined");
        }
        return beanDefinition;
    }
}
```

### 1.2 创建测试用的 Bean 类

```java
package org.winterframework.test;

/**
 * 用户服务 - 测试用的 Bean
 */
public class UserService {
    
    private String name = "UserService";
    
    public void sayHello() {
        System.out.println("Hello from " + name);
    }
    
    public String getName() {
        return name;
    }
}
```

### 1.3 编写测试用例

```java
package org.winterframework.test;

import org.junit.Test;
import org.winterframework.beans.factory.config.BeanDefinition;
import org.winterframework.beans.factory.support.DefaultListableBeanFactory;

import static org.assertj.core.api.Assertions.assertThat;

/**
 * Bean 容器测试
 */
public class BeanFactoryTest {

    @Test
    public void testBeanFactory() {
        // 1. 创建 BeanFactory
        DefaultListableBeanFactory beanFactory = new DefaultListableBeanFactory();

        // 2. 注册 Bean 定义
        BeanDefinition beanDefinition = new BeanDefinition(UserService.class);
        beanFactory.registerBeanDefinition("userService", beanDefinition);

        // 3. 第一次获取 Bean（从无到有，需要创建）
        UserService userService1 = (UserService) beanFactory.getBean("userService");
        assertThat(userService1).isNotNull();
        assertThat(userService1.getName()).isEqualTo("UserService");
        userService1.sayHello();

        // 4. 第二次获取 Bean（从缓存中获取，验证单例）
        UserService userService2 = (UserService) beanFactory.getBean("userService");
        assertThat(userService2).isNotNull();

        // 5. 验证是同一个实例（单例模式）
        assertThat(userService1).isSameAs(userService2);
        System.out.println("userService1 == userService2: " + (userService1 == userService2));
    }
}
```

## 二、运行流程说明

### 2.1 第一次调用 getBean("userService")

```
1. 用户调用: beanFactory.getBean("userService")
   ↓
2. 进入 AbstractBeanFactory.getBean()
   ↓
3. 调用 getSingleton("userService")
   → 返回 null（缓存中不存在）
   ↓
4. 调用 getBeanDefinition("userService")
   → 从 beanDefinitionMap 中获取 BeanDefinition
   ↓
5. 调用 createBean("userService", beanDefinition)
   ↓
6. 进入 AbstractAutowireCapableBeanFactory.doCreateBean()
   ↓
7. 通过反射创建实例: UserService.class.newInstance()
   ↓
8. 调用 addSingleton("userService", bean)
   → 将 Bean 放入 singletonObjects 缓存
   ↓
9. 返回 Bean 实例
```

**控制台输出**:
```
Hello from UserService
```

### 2.2 第二次调用 getBean("userService")

```
1. 用户调用: beanFactory.getBean("userService")
   ↓
2. 进入 AbstractBeanFactory.getBean()
   ↓
3. 调用 getSingleton("userService")
   → 返回缓存中的 Bean（缓存命中！）
   ↓
4. 直接返回 Bean，不再创建
```

**关键点**: 第二次不会创建新对象，直接从缓存返回，这就是**单例模式**！

**控制台输出**:
```
userService1 == userService2: true
```

## 三、核心概念理解

### 3.1 BeanDefinition vs Bean 实例

| 概念 | 说明 | 阶段 | 数量 |
|------|------|------|------|
| **BeanDefinition** | Bean 的配置信息（元数据） | 容器初始化时注册 | 每个 Bean 一个 |
| **Bean 实例** | 真正的对象实例 | 第一次 getBean 时创建 | 单例：一个；原型：多个 |

**类比**:
- `BeanDefinition` 像是"建筑图纸"，描述如何建造
- `Bean 实例` 像是"建筑物本身"，真正可用的对象

### 3.2 单例缓存的作用

```java
// 第一次调用 - 创建新对象
UserService service1 = beanFactory.getBean("userService");  // 创建 + 缓存

// 后续调用 - 直接返回缓存
UserService service2 = beanFactory.getBean("userService");  // 缓存返回
UserService service3 = beanFactory.getBean("userService");  // 缓存返回

// service1 == service2 == service3  (同一个对象)
```

**好处**:
1. ✅ **性能优化**: 避免重复创建对象
2. ✅ **状态共享**: 单例对象可以保持状态
3. ✅ **资源节省**: 减少内存占用

## 五、当前限制

### 5.1 必须有无参构造器

❌ **错误示例**:
```java
public class UserService {
    private String name;
    
    // 只有有参构造器，没有无参构造器
    public UserService(String name) {
        this.name = name;
    }
}
```

✅ **正确示例**:
```java
public class UserService {
    private String name;
    
    // 提供无参构造器
    public UserService() {
    }
    
    // 也可以有有参构造器
    public UserService(String name) {
        this.name = name;
    }
}
```

### 5.2 不支持Bean之间的依赖注入（暂未实现）

当前版本支持基本属性注入，但不支持Bean之间的依赖关系注入：

```java
public class OrderService {
    // 这个Bean依赖不会被自动注入
    private UserService userService;  // null
    
    public void createOrder() {
        userService.sayHello();  // NullPointerException!
    }
}
```

**已实现**: 基本属性注入（String、int等基本类型）
**待实现**: Bean之间的依赖关系注入

## 六、属性注入功能（新特性）

### 6.1 属性注入概述

Winter Framework 现在支持基本的属性注入功能，可以在创建Bean时自动设置属性值。

**核心组件**:
- `PropertyValue`: 封装单个属性信息（属性名 + 属性值）
- `PropertyValues`: 管理Bean的所有属性值
- `BeanDefinition`: 支持属性值配置
- `AbstractAutowireCapableBeanFactory`: 实现属性注入逻辑

### 6.2 基本属性注入示例

```java
@Test
public void testPropertyInjection() {
    // 1. 创建BeanFactory
    DefaultListableBeanFactory beanFactory = new DefaultListableBeanFactory();
    
    // 2. 创建属性值集合
    PropertyValues propertyValues = new PropertyValues();
    propertyValues.addPropertyValue(new PropertyValue("name", "张三"));
    propertyValues.addPropertyValue(new PropertyValue("age", 25));
    propertyValues.addPropertyValue(new PropertyValue("email", "zhangsan@example.com"));
    
    // 3. 创建Bean定义，指定Bean类型和属性值
    BeanDefinition beanDefinition = new BeanDefinition(Person.class, propertyValues);
    
    // 4. 注册Bean定义
    beanFactory.registerBeanDefinition("person", beanDefinition);
    
    // 5. 获取Bean实例（自动进行属性注入）
    Person person = (Person) beanFactory.getBean("person");
    
    // 6. 验证属性注入结果
    assertThat(person.getName()).isEqualTo("张三");
    assertThat(person.getAge()).isEqualTo(25);
    assertThat(person.getEmail()).isEqualTo("zhangsan@example.com");
    
    System.out.println("✅ 属性注入成功: " + person);
}
```

### 6.3 支持的数据类型

Winter Framework 支持以下类型的属性注入：

| 类型 | 示例 | 说明 |
|------|------|------|
| **基本类型** | `int age = 25` | 自动类型转换 |
| **包装类型** | `Integer count = 100` | 自动装箱/拆箱 |
| **字符串** | `String name = "张三"` | 直接赋值 |
| **布尔类型** | `boolean active = true` | 自动转换 |
| **浮点类型** | `double salary = 5000.0` | 自动转换 |

### 6.4 便捷的Bean定义方式

```java
// 方式1：使用BeanDefinition的便捷方法
BeanDefinition beanDefinition = new BeanDefinition(Person.class);
beanDefinition.addPropertyValue("name", "李四");
beanDefinition.addPropertyValue("age", 30);

// 方式2：使用PropertyValues
PropertyValues propertyValues = new PropertyValues();
propertyValues.addPropertyValue(new PropertyValue("name", "王五"));
propertyValues.addPropertyValue(new PropertyValue("age", 28));
BeanDefinition beanDefinition2 = new BeanDefinition(Person.class, propertyValues);
```

### 6.5 属性注入的异常处理

```java
@Test(expected = BeanException.class)
public void testPropertyInjectionError() {
    DefaultListableBeanFactory beanFactory = new DefaultListableBeanFactory();
    
    // 设置不存在的属性名
    PropertyValues propertyValues = new PropertyValues();
    propertyValues.addPropertyValue(new PropertyValue("nonExistentField", "value"));
    
    BeanDefinition beanDefinition = new BeanDefinition(Person.class, propertyValues);
    beanFactory.registerBeanDefinition("person", beanDefinition);
    
    // 这会抛出BeanException
    beanFactory.getBean("person");
}
```

## 七、实例化策略

### 7.1 策略模式应用

Winter Framework 支持两种 Bean 实例化策略：

| 策略类 | 实现方式 | 优点 | 缺点 | 适用场景 |
|--------|---------|------|------|----------|
| **SimpleInstantiationStrategy** | JDK 反射 | 简单、无额外依赖、性能好 | 只支持无参构造器 | 普通 Bean |
| **CglibSubclassInstantiationStrategy** | Cglib 动态代理 | 支持方法拦截、为 AOP 做准备 | 需要 Cglib 依赖、性能略低 | 需要 AOP 的 Bean |

### 7.2 使用 JDK 反射策略（默认）

```java
@Test
public void testSimpleInstantiationStrategy() {
    // 1. 创建 BeanFactory
    DefaultListableBeanFactory beanFactory = new DefaultListableBeanFactory();
    
    // 2. 默认使用 SimpleInstantiationStrategy
    // 无需手动设置，框架默认就是这个策略
    
    // 3. 注册和获取 Bean
    beanFactory.registerBeanDefinition("userService", 
        new BeanDefinition(UserService.class));
    UserService userService = (UserService) beanFactory.getBean("userService");
    
    assertThat(userService).isNotNull();
    System.out.println("✅ 使用 JDK 反射创建 Bean 成功");
}
```

### 7.3 使用 Cglib 代理策略

```java
@Test
public void testCglibInstantiationStrategy() {
    // 1. 创建 BeanFactory
    DefaultListableBeanFactory beanFactory = new DefaultListableBeanFactory();
    
    // 2. 切换为 Cglib 实例化策略
    beanFactory.setInstantiationStrategy(new CglibSubclassInstantiationStrategy());
    
    // 3. 注册和获取 Bean
    beanFactory.registerBeanDefinition("userService", 
        new BeanDefinition(UserService.class));
    UserService userService = (UserService) beanFactory.getBean("userService");
    
    assertThat(userService).isNotNull();
    // 注意：此时获取的是 Cglib 生成的子类代理对象
    System.out.println("Bean 实际类型: " + userService.getClass().getName());
    // 输出: Bean 实际类型: UserService$$EnhancerByCGLIB$$xxx
    
    System.out.println("✅ 使用 Cglib 代理创建 Bean 成功");
}
```

### 7.4 策略切换示例

```java
@Test
public void testSwitchInstantiationStrategy() {
    DefaultListableBeanFactory beanFactory = new DefaultListableBeanFactory();
    
    // 场景1: 使用 JDK 反射创建普通 Bean
    beanFactory.setInstantiationStrategy(new SimpleInstantiationStrategy());
    beanFactory.registerBeanDefinition("service1", 
        new BeanDefinition(UserService.class));
    Object bean1 = beanFactory.getBean("service1");
    System.out.println("Bean1 类型: " + bean1.getClass().getName());
    // 输出: Bean1 类型: UserService
    
    // 场景2: 切换为 Cglib，创建需要 AOP 的 Bean
    beanFactory.setInstantiationStrategy(new CglibSubclassInstantiationStrategy());
    beanFactory.registerBeanDefinition("service2", 
        new BeanDefinition(OrderService.class));
    Object bean2 = beanFactory.getBean("service2");
    System.out.println("Bean2 类型: " + bean2.getClass().getName());
    // 输出: Bean2 类型: OrderService$$EnhancerByCGLIB$$xxx
}
```

### 7.5 策略模式的优势

```java
// ✅ 策略模式的好处：开闭原则
// 1. 对扩展开放：可以轻松添加新的实例化策略
// 2. 对修改关闭：添加新策略不需要修改现有代码

// 假设未来要添加新的实例化策略（如 Javassist）
public class JavassistInstantiationStrategy implements InstantiationStrategy {
    @Override
    public Object instantiate(BeanDefinition beanDefinition) {
        // 使用 Javassist 实现实例化逻辑
        return null;
    }
}

// 使用时只需切换策略，无需修改框架代码
beanFactory.setInstantiationStrategy(new JavassistInstantiationStrategy());
```

### 7.6 Cglib 代理原理简介

```
【Cglib 代理机制】

原始类: UserService
    |
    v
Cglib 动态生成子类: UserService$$EnhancerByCGLIB$$12345678
    |
    +-- 继承 UserService
    +-- 重写所有非 final 方法
    +-- 添加方法拦截器（MethodInterceptor）
    |
    v
代理对象可以在方法调用前后添加增强逻辑（AOP 基础）

示例：
原始方法调用:
    userService.sayHello()

Cglib 代理后:
    1. 拦截器前置处理
    2. 调用原始方法 sayHello()
    3. 拦截器后置处理
```

## 八、与 Spring 对比使用

### 8.1 Winter Framework

```java
// 1. 手动创建 BeanFactory
DefaultListableBeanFactory beanFactory = new DefaultListableBeanFactory();

// 2. 手动注册 BeanDefinition
BeanDefinition beanDefinition = new BeanDefinition(UserService.class);
beanFactory.registerBeanDefinition("userService", beanDefinition);

// 3. 获取 Bean
UserService userService = (UserService) beanFactory.getBean("userService");
```

### 8.2 Spring Framework

```java
// 1. 创建 ApplicationContext（自动扫描和注册）
ApplicationContext context = new AnnotationConfigApplicationContext(AppConfig.class);

// 2. 获取 Bean（无需手动注册）
UserService userService = context.getBean(UserService.class);
```

**区别**:
- Winter: 手动注册，适合理解原理
- Spring: 自动扫描，适合实际开发

### 9.1 添加日志输出

在关键方法中添加日志，观察执行流程：

```java
@Override
public Object getBean(String name) throws BeanException {
    System.out.println(">>> 开始获取 Bean: " + name);
    
    Object bean = getSingleton(name);
    if (bean != null) {
        System.out.println("<<< 从缓存返回 Bean: " + name);
        return bean;
    }
    
    System.out.println("--- 缓存未命中，开始创建 Bean: " + name);
    BeanDefinition beanDefinition = getBeanDefinition(name);
    bean = createBean(name, beanDefinition);
    System.out.println("<<< Bean 创建完成: " + name);
    
    return bean;
}
```

**输出示例**:
```
>>> 开始获取 Bean: userService
--- 缓存未命中，开始创建 Bean: userService
<<< Bean 创建完成: userService

>>> 开始获取 Bean: userService
<<< 从缓存返回 Bean: userService
```

## 十、总结

通过这个示例，你应该理解了：

1. ✅ **如何使用 Winter Framework**: 注册 BeanDefinition → 获取 Bean
2. ✅ **单例模式的实现**: 通过缓存确保同一个 Bean 只创建一次
3. ✅ **模板方法模式**: getBean 定义流程，子类实现细节
4. ✅ **策略模式的应用**: 灵活切换不同的实例化策略（JDK 反射 vs Cglib 代理）
5. ✅ **IoC 容器的本质**: 对象的创建和管理交给容器
6. ✅ **为 AOP 做准备**: Cglib 代理为后续实现面向切面编程提供基础
7. ✅ **属性注入的实现**: 通过 PropertyValue 和 PropertyValues 实现属性自动设置 ⭐ 新增
8. ✅ **工具库的集成**: 使用 Hutool 简化反射操作，提高开发效率 ⭐ 新增

这正是 Spring IoC 容器的核心原理！🎯
