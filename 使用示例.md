# Winter Framework 使用示例

## 一、基本使用

### 1.1 手动注册Bean定义

```java
// 1. 创建BeanFactory
DefaultListableBeanFactory beanFactory = new DefaultListableBeanFactory();

// 2. 创建Bean定义
BeanDefinition beanDefinition = new BeanDefinition(UserService.class);

// 3. 注册Bean定义
beanFactory.registerBeanDefinition("userService", beanDefinition);

// 4. 获取Bean实例
UserService userService = (UserService) beanFactory.getBean("userService");
```

### 1.2 带属性注入的Bean定义

```java
// 1. 创建BeanFactory
DefaultListableBeanFactory beanFactory = new DefaultListableBeanFactory();

// 2. 创建Bean定义并添加属性
BeanDefinition beanDefinition = new BeanDefinition(UserService.class);
beanDefinition.addPropertyValue("name", "derek");
beanDefinition.addPropertyValue("age", 25);

// 3. 注册Bean定义
beanFactory.registerBeanDefinition("userService", beanDefinition);

// 4. 获取Bean实例
UserService userService = (UserService) beanFactory.getBean("userService");
System.out.println(userService.getName()); // derek
System.out.println(userService.getAge());  // 25
```

## 二、XML配置使用

### 2.1 基本XML配置

**spring.xml**:
```xml
<?xml version="1.0" encoding="UTF-8"?>
<beans xmlns="http://www.springframework.org/schema/beans"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
       xsi:schemaLocation="http://www.springframework.org/schema/beans
                           http://www.springframework.org/schema/beans/spring-beans.xsd">

    <bean id="userService" class="com.example.UserService">
        <property name="name" value="derek"/>
        <property name="age" value="25"/>
    </bean>

</beans>
```

**Java代码**:
```java
// 1. 创建BeanFactory和XML读取器
DefaultListableBeanFactory beanFactory = new DefaultListableBeanFactory();
XmlBeanDefinitionReader reader = new XmlBeanDefinitionReader(beanFactory);

// 2. 从XML文件加载Bean定义
reader.loadBeanDefinitions("classpath:spring.xml");

// 3. 获取Bean实例
UserService userService = (UserService) beanFactory.getBean("userService");
```

### 2.2 Bean依赖注入

**Person类**:
```java
public class Person {
    private String name;
    private int age;
    private Car car;
    
    // getter/setter方法...
}
```

**Car类**:
```java
public class Car {
    private String brand;
    private String model;
    
    // getter/setter方法...
}
```

**spring.xml**:
```xml
<?xml version="1.0" encoding="UTF-8"?>
<beans xmlns="http://www.springframework.org/schema/beans"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
       xsi:schemaLocation="http://www.springframework.org/schema/beans
                           http://www.springframework.org/schema/beans/spring-beans.xsd">

    <bean id="person" class="com.example.Person">
        <property name="name" value="derek"/>
        <property name="age" value="25"/>
        <property name="car" ref="car"/>
    </bean>

    <bean id="car" class="com.example.Car">
        <property name="brand" value="porsche"/>
        <property name="model" value="911"/>
    </bean>

</beans>
```

**Java代码**:
```java
// 1. 创建BeanFactory和XML读取器
DefaultListableBeanFactory beanFactory = new DefaultListableBeanFactory();
XmlBeanDefinitionReader reader = new XmlBeanDefinitionReader(beanFactory);

// 2. 从XML文件加载Bean定义
reader.loadBeanDefinitions("classpath:spring.xml");

// 3. 获取Bean实例
Person person = (Person) beanFactory.getBean("person");
Car car = (Car) beanFactory.getBean("car");

// 4. 验证依赖注入
System.out.println(person.getName()); // derek
System.out.println(person.getCar().getBrand()); // porsche
System.out.println(car.getBrand()); // porsche
```

### 2.3 Bean命名策略

Winter Framework支持三种Bean命名策略：

1. **使用id属性**（推荐）:
```xml
<bean id="userService" class="com.example.UserService"/>
```

2. **使用name属性**:
```xml
<bean name="userService" class="com.example.UserService"/>
```

3. **自动生成**（使用类名首字母小写）:
```xml
<bean class="com.example.UserService"/>
<!-- Bean名称自动生成为: userService -->
```

## 三、实例化策略

### 3.1 默认策略（JDK反射）

```java
// 使用默认策略
DefaultListableBeanFactory beanFactory = new DefaultListableBeanFactory();
beanFactory.registerBeanDefinition("service", new BeanDefinition(UserService.class));
UserService service = (UserService) beanFactory.getBean("service");
// service是通过JDK反射创建的普通对象
```

### 3.2 Cglib动态代理策略

```java
// 切换到Cglib策略
DefaultListableBeanFactory beanFactory = new DefaultListableBeanFactory();
beanFactory.setInstantiationStrategy(new CglibSubclassInstantiationStrategy());
beanFactory.registerBeanDefinition("service", new BeanDefinition(UserService.class));
UserService service = (UserService) beanFactory.getBean("service");
// service是通过Cglib创建的代理对象
```

## 六、错误处理

### 6.1 常见异常

1. **Bean类找不到**:
```
BeanException: Cannot find class [com.example.NonExistentClass]
```

2. **Bean名称重复**:
```
BeanException: Duplicate beanName[userService] is not allowed
```

3. **属性名称为空**:
```
BeanException: The name attribute cannot be null or empty
```

4. **XML解析失败**:
```
BeanException: IOException parsing XML document from classpath:spring.xml
```

### 6.2 异常处理示例

```java
try {
    reader.loadBeanDefinitions("classpath:spring.xml");
    UserService userService = (UserService) beanFactory.getBean("userService");
} catch (BeanException e) {
    System.err.println("Bean配置错误: " + e.getMessage());
    e.printStackTrace();
}
```

## 七、最佳实践

### 7.1 XML配置最佳实践

1. **使用有意义的Bean名称**:
```xml
<bean id="userService" class="com.example.UserService"/>
<!-- 而不是 -->
<bean id="service" class="com.example.UserService"/>
```

2. **合理使用ref和value**:
```xml
<!-- 基本类型使用value -->
<property name="age" value="25"/>

<!-- 对象引用使用ref -->
<property name="userService" ref="userService"/>
```

3. **保持XML格式整洁**:
```xml
<bean id="userService" class="com.example.UserService">
    <property name="name" value="derek"/>
    <property name="age" value="25"/>
    <property name="car" ref="car"/>
</bean>
```

### 7.2 代码组织最佳实践

1. **分离配置和代码**:
   - 将Bean定义放在XML文件中
   - 将业务逻辑放在Java类中

2. **使用包扫描**（待实现）:
   - 将相关类放在同一个包下
   - 使用有意义的包名

3. **异常处理**:
   - 在应用启动时检查配置
   - 提供清晰的错误信息

## 九、性能优化建议

1. **使用单例Bean**: 默认就是单例，避免重复创建
2. **合理使用缓存**: Bean实例会被缓存，避免重复获取
3. **延迟加载**: 只在需要时创建Bean实例
4. **避免循环依赖**: 设计时避免Bean之间的循环引用
