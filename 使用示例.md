# Winter Framework 使用示例

## 一、快速开始

### 1.1 创建一个具体的 BeanFactory 实现

首先需要创建一个继承 `AbstractAutowireCapableBeanFactory` 的具体实现类，实现 `getBeanDefinition` 方法：

```java
package org.winterframework.beans.factory.support;

import org.winterframework.beans.BeanException;
import org.winterframework.beans.factory.config.BeanDefinition;

import java.util.HashMap;
import java.util.Map;

/**
 * 默认可列表的 Bean 工厂
 * 实现了 BeanDefinitionRegistry 接口，可以注册和管理 BeanDefinition
 */
public class DefaultListableBeanFactory extends AbstractAutowireCapableBeanFactory 
        implements BeanDefinitionRegistry {

    // 存储 BeanDefinition 的 Map
    private Map<String, BeanDefinition> beanDefinitionMap = new HashMap<>();

    @Override
    public void registerBeanDefinition(String beanName, BeanDefinition beanDefinition) {
        beanDefinitionMap.put(beanName, beanDefinition);
    }

    @Override
    protected BeanDefinition getBeanDefinition(String beanName) throws BeanException {
        BeanDefinition beanDefinition = beanDefinitionMap.get(beanName);
        if (beanDefinition == null) {
            throw new BeanException("No bean named '" + beanName + "' is defined");
        }
        return beanDefinition;
    }
}
```

### 1.2 创建测试用的 Bean 类

```java
package org.winterframework.test;

/**
 * 用户服务 - 测试用的 Bean
 */
public class UserService {
    
    private String name = "UserService";
    
    public void sayHello() {
        System.out.println("Hello from " + name);
    }
    
    public String getName() {
        return name;
    }
}
```

### 1.3 编写测试用例

```java
package org.winterframework.test;

import org.junit.Test;
import org.winterframework.beans.factory.config.BeanDefinition;
import org.winterframework.beans.factory.support.DefaultListableBeanFactory;

import static org.assertj.core.api.Assertions.assertThat;

/**
 * Bean 容器测试
 */
public class BeanFactoryTest {

    @Test
    public void testBeanFactory() {
        // 1. 创建 BeanFactory
        DefaultListableBeanFactory beanFactory = new DefaultListableBeanFactory();

        // 2. 注册 Bean 定义
        BeanDefinition beanDefinition = new BeanDefinition(UserService.class);
        beanFactory.registerBeanDefinition("userService", beanDefinition);

        // 3. 第一次获取 Bean（从无到有，需要创建）
        UserService userService1 = (UserService) beanFactory.getBean("userService");
        assertThat(userService1).isNotNull();
        assertThat(userService1.getName()).isEqualTo("UserService");
        userService1.sayHello();

        // 4. 第二次获取 Bean（从缓存中获取，验证单例）
        UserService userService2 = (UserService) beanFactory.getBean("userService");
        assertThat(userService2).isNotNull();

        // 5. 验证是同一个实例（单例模式）
        assertThat(userService1).isSameAs(userService2);
        System.out.println("userService1 == userService2: " + (userService1 == userService2));
    }
}
```

## 二、运行流程说明

### 2.1 第一次调用 getBean("userService")

```
1. 用户调用: beanFactory.getBean("userService")
   ↓
2. 进入 AbstractBeanFactory.getBean()
   ↓
3. 调用 getSingleton("userService")
   → 返回 null（缓存中不存在）
   ↓
4. 调用 getBeanDefinition("userService")
   → 从 beanDefinitionMap 中获取 BeanDefinition
   ↓
5. 调用 createBean("userService", beanDefinition)
   ↓
6. 进入 AbstractAutowireCapableBeanFactory.doCreateBean()
   ↓
7. 通过反射创建实例: UserService.class.newInstance()
   ↓
8. 调用 addSingleton("userService", bean)
   → 将 Bean 放入 singletonObjects 缓存
   ↓
9. 返回 Bean 实例
```

**控制台输出**:
```
Hello from UserService
```

### 2.2 第二次调用 getBean("userService")

```
1. 用户调用: beanFactory.getBean("userService")
   ↓
2. 进入 AbstractBeanFactory.getBean()
   ↓
3. 调用 getSingleton("userService")
   → 返回缓存中的 Bean（缓存命中！）
   ↓
4. 直接返回 Bean，不再创建
```

**关键点**: 第二次不会创建新对象，直接从缓存返回，这就是**单例模式**！

**控制台输出**:
```
userService1 == userService2: true
```

## 三、核心概念理解

### 3.1 BeanDefinition vs Bean 实例

| 概念 | 说明 | 阶段 | 数量 |
|------|------|------|------|
| **BeanDefinition** | Bean 的配置信息（元数据） | 容器初始化时注册 | 每个 Bean 一个 |
| **Bean 实例** | 真正的对象实例 | 第一次 getBean 时创建 | 单例：一个；原型：多个 |

**类比**:
- `BeanDefinition` 像是"建筑图纸"，描述如何建造
- `Bean 实例` 像是"建筑物本身"，真正可用的对象

### 3.2 单例缓存的作用

```java
// 第一次调用 - 创建新对象
UserService service1 = beanFactory.getBean("userService");  // 创建 + 缓存

// 后续调用 - 直接返回缓存
UserService service2 = beanFactory.getBean("userService");  // 缓存返回
UserService service3 = beanFactory.getBean("userService");  // 缓存返回

// service1 == service2 == service3  (同一个对象)
```

**好处**:
1. ✅ **性能优化**: 避免重复创建对象
2. ✅ **状态共享**: 单例对象可以保持状态
3. ✅ **资源节省**: 减少内存占用

## 四、扩展示例

### 4.1 注册多个 Bean

```java
@Test
public void testMultipleBeans() {
    DefaultListableBeanFactory beanFactory = new DefaultListableBeanFactory();

    // 注册多个 Bean
    beanFactory.registerBeanDefinition("userService", 
        new BeanDefinition(UserService.class));
    beanFactory.registerBeanDefinition("orderService", 
        new BeanDefinition(OrderService.class));
    beanFactory.registerBeanDefinition("productService", 
        new BeanDefinition(ProductService.class));

    // 获取不同的 Bean
    UserService userService = (UserService) beanFactory.getBean("userService");
    OrderService orderService = (OrderService) beanFactory.getBean("orderService");
    ProductService productService = (ProductService) beanFactory.getBean("productService");

    assertThat(userService).isNotNull();
    assertThat(orderService).isNotNull();
    assertThat(productService).isNotNull();
}
```

### 4.2 测试 Bean 不存在的情况

```java
@Test(expected = BeanException.class)
public void testBeanNotFound() {
    DefaultListableBeanFactory beanFactory = new DefaultListableBeanFactory();

    // 尝试获取未注册的 Bean
    beanFactory.getBean("nonExistentBean");  // 抛出 BeanException
}
```

## 五、当前限制

### 5.1 必须有无参构造器

❌ **错误示例**:
```java
public class UserService {
    private String name;
    
    // 只有有参构造器，没有无参构造器
    public UserService(String name) {
        this.name = name;
    }
}
```

✅ **正确示例**:
```java
public class UserService {
    private String name;
    
    // 提供无参构造器
    public UserService() {
    }
    
    // 也可以有有参构造器
    public UserService(String name) {
        this.name = name;
    }
}
```

### 5.2 不支持依赖注入（暂未实现）

当前版本无法自动注入依赖：

```java
public class OrderService {
    // 这个依赖不会被自动注入
    private UserService userService;  // null
    
    public void createOrder() {
        userService.sayHello();  // NullPointerException!
    }
}
```

**解决方案**: 后续版本需要实现属性注入功能。

## 六、与 Spring 对比使用

### 6.1 Winter Framework

```java
// 1. 手动创建 BeanFactory
DefaultListableBeanFactory beanFactory = new DefaultListableBeanFactory();

// 2. 手动注册 BeanDefinition
BeanDefinition beanDefinition = new BeanDefinition(UserService.class);
beanFactory.registerBeanDefinition("userService", beanDefinition);

// 3. 获取 Bean
UserService userService = (UserService) beanFactory.getBean("userService");
```

### 6.2 Spring Framework

```java
// 1. 创建 ApplicationContext（自动扫描和注册）
ApplicationContext context = new AnnotationConfigApplicationContext(AppConfig.class);

// 2. 获取 Bean（无需手动注册）
UserService userService = context.getBean(UserService.class);
```

**区别**:
- Winter: 手动注册，适合理解原理
- Spring: 自动扫描，适合实际开发

## 七、调试技巧

### 7.1 添加日志输出

在关键方法中添加日志，观察执行流程：

```java
@Override
public Object getBean(String name) throws BeanException {
    System.out.println(">>> 开始获取 Bean: " + name);
    
    Object bean = getSingleton(name);
    if (bean != null) {
        System.out.println("<<< 从缓存返回 Bean: " + name);
        return bean;
    }
    
    System.out.println("--- 缓存未命中，开始创建 Bean: " + name);
    BeanDefinition beanDefinition = getBeanDefinition(name);
    bean = createBean(name, beanDefinition);
    System.out.println("<<< Bean 创建完成: " + name);
    
    return bean;
}
```

**输出示例**:
```
>>> 开始获取 Bean: userService
--- 缓存未命中，开始创建 Bean: userService
<<< Bean 创建完成: userService

>>> 开始获取 Bean: userService
<<< 从缓存返回 Bean: userService
```

## 八、总结

通过这个示例，你应该理解了：

1. ✅ **如何使用 Winter Framework**: 注册 BeanDefinition → 获取 Bean
2. ✅ **单例模式的实现**: 通过缓存确保同一个 Bean 只创建一次
3. ✅ **模板方法模式**: getBean 定义流程，子类实现细节
4. ✅ **IoC 容器的本质**: 对象的创建和管理交给容器

这正是 Spring IoC 容器的核心原理！🎯
